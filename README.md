# 发货清单生成器（在线版）

浏览器内完成装箱录入与发货清单生成，数据不上传服务器。

## 在线访问

部署 GitHub Pages 后，访问：

`https://<你的用户名>.github.io/shipping-manifest-web/`

## 使用说明

1. 打开页面后，上传或拖入 `data.xlsx` 产品数据表
2. 若将 `data.xlsx` 放在仓库根目录并推送，页面会自动加载默认数据表
3. 录入箱数、重量、SKU 与装箱信息（格式：`箱号/数量`，如 `5/30`）
4. 点击「生成清单」，可下载含图片的 Excel

## 本地预览

双击 `启动本地服务.ps1`，浏览器访问 http://localhost:5173/
